# Ankara Sincan Police Station - Info Portal 

This is an informational web application designed to provide citizens with quick, accurate, and accessible information regarding the working hours within the Ankara Sincan Police Station.

## Project Overview

Navigating bureaucratic and governmental structures can sometimes be confusing for citizens. This project aims to solve that problem by centralizing the working hours of the Sincan Police Station into a single, user-friendly, and responsive web interface.

## Key Features

- **Working Hours Directory:** Clear and precise operational hours for each specific unit to prevent unnecessary visits.
- **Responsive Design:** Fully optimized for mobile and desktop screens, ensuring citizens can access the information on the go.
- **Clean & Accessible UI:** A minimalist user interface designed for readability and quick access to information.

## Tech Stack

- **Frontend:** HTML5, CSS3, Vanilla JavaScript
